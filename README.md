# تقویم

تقویم ایرانی با رابط کاربری فارسی و راست‌چین. الهام‌گرفته از `time.ir`، با هویت بصری مدرنِ ایرانی.

نسخهٔ زنده: [taghv.im](https://taghv.im)

![نشان تقویم](src/app/icon.svg)

## امکانات

- نمایش زمان زندهٔ تهران
- تاریخ شمسی، میلادی و قمری به‌صورت هم‌زمان
- تقویم ماهانهٔ شمسی با شروع هفته از شنبه
- رویدادها و تعطیلی‌های رسمیِ برگزیده
- پیش‌فرض سکولار: مناسبت‌های مذهبی و دولتی و اوقات شرعی فقط با روشن‌کردن کلید «مناسبت‌های مذهبی و دولتی» نمایش داده می‌شوند و انتخاب در مرورگر ذخیره می‌شود
- روز میلادی و قمری زیر هر روز تقویم
- ناوبری ماه/سال و بازگشت به امروز
- تبدیل تاریخ بین شمسی، میلادی و قمری
- محاسبهٔ فاصلهٔ بین دو تاریخ و محاسبهٔ سن
- یادبود جاویدنامان: در هر بارگذاری، یک نام و عکس تصادفی از فهرست شناسایی‌شدگان ۱۸ و ۱۹ دی (منبع: جاویدنامان ایران اینترنشنال)
- اوقات شرعی برای ۱۲ شهر ایران (با روشن‌کردن کلید)
- ذخیرهٔ شهر انتخاب‌شده و وضعیت کلید مناسبت‌ها در مرورگر
- چیدمان راست‌چین و واکنش‌گرا روی دسکتاپ و موبایل
- پشتیبانی کیبورد برای ناوبری سلول‌ها و زبانه‌ها
- بدون حساب کاربری، بدون تبلیغات، بدون پایگاه داده

## پشتهٔ فنی

- Next.js App Router
- React 19
- TypeScript
- Tailwind CSS v4
- `jalaali-js` برای تبدیل شمسی
- `adhan` برای اوقات شرعی
- `lucide-react` برای آیکن‌ها
- `@fontsource/vazirmatn` برای تایپوگرافی فارسی
- Vitest برای تست‌های واحد
- Playwright برای تست‌های مرورگر

## شروع سریع

```bash
npm install
npm run dev -- --port 3100
```

سپس مرورگر را روی `http://127.0.0.1:3100` باز کنید.

> پورت `3000` روی این ماشین اشغال است؛ به‌همین دلیل از `3100` استفاده می‌شود. لطفاً پردازش‌های نامرتبط روی پورت `3000` را متوقف نکنید.

## اسکریپت‌ها

| دستور | توضیح |
| --- | --- |
| `npm install` | نصب وابستگی‌ها |
| `npm run dev -- --port 3100` | سرور توسعه روی پورت ۳۱۰۰ |
| `npm test` | تست‌های واحد با Vitest |
| `npm run typecheck` | بررسی TypeScript |
| `npm run build` | ساخت نسخهٔ تولید |
| `npm run test:e2e` | تست‌های مرورگر با Playwright |
| `npm run sync:javidnaman` | به‌روزرسانی فهرست جاویدنامان از سایت منبع (دستی) |

برای اجرای تست‌های مرورگر، ابتدا یک‌بار Chromium را نصب کنید:

```bash
npx playwright install chromium
```

## ملاحظات داده

- تاریخ‌ها بر اساس روز مدنی در `Asia/Tehran` تفسیر می‌شوند، نه منطقهٔ زمانی ماشین.
- تبدیل‌ها ظهر UTC برمی‌گردند تا پایدار باشند.
- بازهٔ پشتیبانی‌شده: سال‌های شمسی ۱۲۰۰ تا ۱۶۰۰.
- تاریخ‌های قمری از تقویم محاسباتی `islamic-civil` استفاده می‌کنند و ممکن است با تاریخ‌های رصدیِ ایران تفاوت داشته باشند.
- رویدادها مجموعه‌ای برگزیده و تکرارشونده هستند، نه تقویم رسمیِ کامل.
- فهرست جاویدنامان یک عکسِ لحظه‌ای (snapshot) در `src/data` است و فقط نام‌های شناسایی‌شده را دارد؛ عکس‌ها از سرور منبع بارگذاری می‌شوند.
- تعطیلات قمری فقط برای سه تاریخ از سال ۱۴۰۵ به تقویم رسمی پین شده‌اند؛ بقیه محاسباتی‌اند.
- اوقات شرعی با روش محاسبهٔ تهران و مختصات شهرها محاسبه می‌شوند.
- نیمه‌شب شرعی، میانگینِ غروب تا فجر روز بعد است.
- ساعت زنده از ساعت دستگاه در زمان تهران استفاده می‌کند، نه همگام‌سازی NTP.
