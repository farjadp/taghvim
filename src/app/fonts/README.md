# قلم‌های تجاری

این دو فایل با بقیهٔ قلم‌های پروژه فرق دارند و مجوزشان جداست.

| فایل | خانواده | منبع | مجوز |
| --- | --- | --- | --- |
| `IRANSansXV.woff2` | IRANSansX | [fontiran.com](https://fontiran.com) | تجاری، خریداری‌شده |
| `IRANYekanXVF.woff2` | IRANYekanX | [fontiran.com](https://fontiran.com) | تجاری، خریداری‌شده |

وزیرمتن، شبنم و ساحل با مجوز SIL OFL می‌آیند و از npm نصب می‌شوند. این دو نه —
پس **هیچ‌جا ننویس که همهٔ قلم‌های پروژه OFL هستند.** استفادهٔ دوبارهٔ این دو فایل
تابع مجوز خودشان است، نه مجوز این ریپو.

## چرا این فایل‌ها، نه بقیهٔ بسته

هر دو **variable** هستند و محور وزنشان ۱۰۰ تا ۱۰۰۰ است، پس یک فایل تمام وزن‌هایی
را که رابط استفاده می‌کند (۴۰۰، ۵۰۰، ۶۰۰، ۷۰۰، ۸۰۰) پوشش می‌دهد — به‌جای پنج فایل
جدا مثل وزیرمتن. مرورگر هم فقط وقتی دانلودشان می‌کند که کاربر همان قلم را انتخاب
کرده باشد.

بستهٔ اصلی نسخهٔ **FaNum** هم دارد. **از آن استفاده نکن.** آن نسخه ارقام لاتین را
با گلیف فارسی رندر می‌کند، و تاریخ میلادی (`2026-09-08`) و ساعت `dir="ltr"` را
خراب می‌کند. اپ ارقام فارسی را خودش با `Intl` می‌سازد، پس چنین قلمی لازم ندارد.

مسیر داخل بسته‌های اصلی:

```
IranSansX(Pro)/Variable/webfont/IRANSansXV.woff2
IRANYekanX(Pro)/Variable Font/webfont/IRANYekanXVF.woff2
```
