# اکستنشن کروم — تب جدید، تقویم

تب جدید مرورگر را با تقویم جایگزین می‌کند: تاریخ امروز و ساعت تهران، ماه جاری، و مناسبت‌های روز. همان چیزی که `@shahram51` زیر تِرد لانچ خواست.

## ساخت و نصب

```bash
npm run build:extension
```

خروجی در `extension/dist/` است (در گیت نادیده گرفته می‌شود). بعد در کروم:

1. `chrome://extensions` را باز کن و **Developer mode** را روشن کن.
2. **Load unpacked** را بزن و پوشهٔ `extension/dist` را انتخاب کن.
3. یک تب جدید باز کن.

هر بار که `build:extension` را دوباره اجرا کنی، در همان صفحه روی «بازخوانی» اکستنشن بزن.

## چه چیزی داخلش هست و چه چیزی نیست

| هست | نیست، عمداً |
| --- | --- |
| تاریخ امروز، روز هفته، ساعت زندهٔ تهران و ساعت شهرها | ابزارهای تاریخ (تبدیل، فاصله، سن) |
| ماه جاری با همان رنگ تعطیلی و اعداد میلادی · قمری | اوقات شرعی |
| مناسبت‌های روز و ماه | یادبود جاویدنامان |
| کلیدهای مذهبی، دولتی، جهانی | صفحهٔ تغییرات، راهنما، درباره |
| پوسته، اندازه و پنج قلم | هر چیزی که شبکه بخواهد |

تب جدید چیزی است که آدم به آن **نگاه** می‌کند، نه چیزی که در آن کار می‌کند. بقیه یک کلیک آن‌طرف‌تر روی [taghv.im](https://taghv.im) است.

## چیزهایی که باید بدانی

**هیچ مجوزی نمی‌خواهد.** `permissions` و `host_permissions` در منیفست خالی‌اند. هیچ درخواست شبکه‌ای وجود ندارد، هیچ آماری جمع نمی‌شود، هیچ کدی از بیرون بارگذاری نمی‌شود. `scripts/check-extension.mjs` بعد از هر بیلد همین‌ها را چک می‌کند و اگر یک `fetch` یا یک نشانی خارجی به بسته راه پیدا کند، بیلد را رد می‌کند.

**تنظیمات سایت به اکستنشن منتقل نمی‌شود.** صفحهٔ اکستنشن origin خودش را دارد (`chrome-extension://…`) و نمی‌تواند `localStorage` سایت taghv.im را بخواند. پس پوسته، قلم و کلیدهای مناسبت از همان پیش‌فرض‌های سایت شروع می‌شوند و جدا ذخیره می‌شوند. این محدودیت مرورگر است، نه یک باگ، و رابط هم چیزی جز این ادعا نمی‌کند.

**کد کپی نشده، ایمپورت شده.** پنل‌ها از `src/components` و منطق از `src/lib` می‌آیند — همان فایل‌هایی که سایت استفاده می‌کند. فقط پوستهٔ تب جدید (`extension/src/new-tab.tsx`) مال اکستنشن است. اگر تقویم سایت درست باشد، این هم درست است؛ اگر چیزی در سایت عوض شود، اینجا هم عوض می‌شود.

**اسکریپت پیش از رسم.** MV3 اسکریپت درون‌خطی را ممنوع می‌کند، پس همان اسکریپتی که سایت برای اعمال پوستهٔ تیره قبل از اولین رسم دارد، به‌عنوان `boot.js` جدا در بیلد تولید می‌شود. برای همین تب تیره فلاش سفید نمی‌زند.

**فقط woff2.** بسته‌های شبنم و ساحل فرمت‌های eot و ttf و woff هم دارند که کروم هرگز لازمشان ندارد. بیلد آن‌ها را حذف و فهرست `src` را بازنویسی می‌کند — ۳٫۶ مگابایت به ۱٫۱ مگابایت رسید.

## تست

- `npm test` — منیفست: MV3، بدون مجوز، آیکن‌ها موجود، نسخه برابر `package.json`.
- `npm run build:extension` — بیلد به‌علاوهٔ بررسی بسته.
- `npm run test:e2e` — صفحهٔ ساخته‌شده را با شبکهٔ مسدود بارگذاری می‌کند و تاریخ تهران را می‌خواند. اگر `extension/dist` نباشد، خودش می‌سازد.
